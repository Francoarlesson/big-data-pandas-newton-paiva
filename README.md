# Análise de Dados com Pandas

Projeto de análise de vendas utilizando Python e Pandas.

## Tecnologias
- Python
- Pandas
- Matplotlib

## Objetivo
Limpar, transformar e analisar dados de vendas.

## Funcionalidades
- Tratamento de dados nulos
- Agrupamentos
- Gráficos
- Exportação CSV

## Como executar

```bash
pip install -r requirements.txt
python main.py
